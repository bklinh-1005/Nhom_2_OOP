# Nhom_2_OOP

HỆ THỐNG ĐĂNG KÝ MÔN HỌC CHO SINH VIÊN

## Yêu cầu môi trường
* Java (JDK) & Maven
* Node.js & npm

## Hướng dẫn khởi chạy

### 1. Chạy Backend (Spring Boot)
Mở terminal tại thư mục gốc của dự án và chạy lệnh sau:
```bash
mvn spring-boot:run
```

### 2. Chạy Frontend
Mở một terminal mới, di chuyển vào thư mục `frontend`, cài đặt thư viện (lần đầu) và khởi chạy:
```bash
cd frontend
npm install
npm run dev
```
